# Sistema Web — Clínica Veterinaria

## 🧰 Tecnologías utilizadas

### Frontend
- **HTML5 semántico** — Uso de `<main>`, `<section>`, `<header>`, `<footer>`, `<nav>` en todas las vistas.
- **CSS3** — Flexbox, Grid, `clamp()`, gradientes, transiciones, `backdrop-filter`.
- **Sass (SCSS)** — Preprocesador con arquitectura modular (abstracts / base / components).
- **Bootstrap 5.3** — Framework de estilos: grid, utilidades, componentes.
- **Bootstrap Icons 1.11** — Iconografía.
- **JavaScript ES6** — Interacciones (mostrar/ocultar contraseña).

### Backend
- **PHP 8** con POO y PDO (consultas preparadas).
- **MySQL** — Base de datos relacional.

### Herramientas
- **XAMPP** — Entorno local.
- **Visual Studio Code** + **Live Sass Compiler**.
